# index — 记忆台账

> **用途**：登记 `MEMORY/` 各文件的分工，以及**每次整理到哪一天**（Agent 靠它知道哪些 `tmp/` 还没归位）。
> **不写什么**：不放章节链接（检索交给 grep + IDE 大纲）；不重复各文件自身的内容。
> **更新方式**：只追加"整理台账"里的一节。
> 热记忆（规矩 / 命令）在项目根 [`../AGENTS.md`](../AGENTS.md)；本文件只管 `MEMORY/`。

---

## 文件分工

### facts.md
- **放什么**：现在是什么样 —— 代码结构地图 + 功能手册（给开发者与 Agent 定位"要改 X 去哪"）
- **更新方式**：就地重写（不追历史、不写日期）

### decisions.md
- **放什么**：为什么这么定 —— 背景 / 选项 / 选择 / 理由；未定的标 `状态: 待定`
- **更新方式**：追加

### lessons.md
- **放什么**：坑与多轮瓶颈（症状 → 根因 → 修法 → 预防）+ 未解决的已知问题
- **更新方式**：追加

### dev_logs.md
- **放什么**：过程与证据 —— 这次怎么做的、验证了什么
- **更新方式**：追加

### tmp/{YYYY-MM-DD}.md
- **放什么**：素材库 —— 每轮对话末尾追加本轮值得入记忆的东西
- **更新方式**：只追加（不改过往、只放素材不放规矩）
- 卡片格式：`## HH:MM:SS — 主题` + 做了什么/结论 + 为什么/证据 + 候选去向 + 状态

### .old/
- **放什么**：废弃归档（`todos.md`、`memory.md`、旧窗帘存档…）
- **更新方式**：只进不出

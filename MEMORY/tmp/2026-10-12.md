## 01:02:40 — 调研结论：三层记忆模型与尺寸预算
- **结论**：项目记忆通行做法分三层 —— **热记忆**（每轮都注入 = 项目 `AGENTS.md`）只放"小而耐久、几乎每轮都用"的东西（仓库用途、精确命令、硬约束与禁令、稳定架构边界、**被反复纠正的工作方式**）；**情节记忆**（按需读 = `MEMORY/`）放决策日志/变更日志/历史；**程序性记忆** = 反复"怎么做"的事**做成脚本或 skill**，而不是往 AGENTS 里加段落
- **关键数字**：主记忆文件 medium/large 项目 **50~100 行**，**>150 行就该把细节挪出去**；**指令预算约 150~200 条**，超了遵守率下降；"能从代码/清单/lint 配置推断的事实**默认不写**进热记忆"；反模式含"把 AGENTS.md 当知识库"（它应是**活的例外清单**，倾向少改、稳定）
- **证据/来源**：[memory-patterns](https://github.com/vasilyu1983/AI-Agents-public/blob/main/frameworks/shared-skills/skills/agents-memory/references/memory-patterns.md)（Pattern 0 分层模型 / 尺寸指南 / 反模式 / Pattern 13 渐进披露 / Pattern 14 Always-Ask-Never / Pattern 15 验证清单 / Pattern 16 战略与意图分离）、[Claude Code 官方记忆文档](https://code.claude.com/docs/en/memory)
- **候选去向**：全局 AGENTS（跨项目规范）
- **状态**：已定
